# Installer

Pour installer:

> L'installation se fait avec `uv`, voir la documentation de `uv` pour l'installer.

1. Installer les packages:
```
uv sync
```

2. Installer le kernel jupyter dans le `.venv`
```
python3 -m ipykernel install
```

3. Sélectionner l'environnement virtuel sur le fichier `.ipynb`
